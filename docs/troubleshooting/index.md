# 困ったとき

問題が起きたら、まず次の順番で確認してください。

1. サービスが起動しているか
2. Control Panel にログインできるか
3. 配信先や Discord の設定が正しいか
4. サーバーの時刻、ネットワーク、ファイアウォールに問題がないか
5. ログにエラーが出ていないか

## よくある原因

- トークンや配信キーの入力間違い
- サーバーから外部サービスへ接続できない
- Discord Bot に必要な権限がない
- YouTube 側の配信枠が準備できていない
- 保存先の容量や権限が足りない

## 編集・枠作成・画像処理で止まったとき

| 状況 | 確認と対応 |
| --- | --- |
| 定期更新後に保存を待っている | 保存直前の権限・設定確認が終わるまで待ちます。入力を残し、表示された競合や権限の理由を確認します。監視表示の更新は続きます |
| 枠を作成できず入力の修正を求められる | [作成エラーの要約と該当項目](/control-panel/streams#create-errors)を確認します。Nodeの割当競合、設定の変更、画像の処理待ちを区別します |
| 2枚目以降の画像がまだ候補に入らない | [画像カードの処理段階](/control-panel/streams#image-processing)と処理件数を確認します。変換が完了した画像だけが利用可能候補になります |
| 作成やアップロードの結果が不明 | 自動再送せず、一覧・監査ログ・画像の結果確認で照合します。通信切断や照合結果0件だけで未作成と判断しません |

問題を報告する場合は、画面名、操作時刻、表示されたエラー分類コード、どの処理段階で止まったかを伝えてください。Token、Cookie、秘密入力、未加工の通信内容は添付しないでください。

## 文字化けしたとき

Windows PowerShell で日本語が崩れて見える場合があります。まずファイル自体ではなく、表示エンコードの問題を疑ってください。UTF-8 として読み直してから判断します。
